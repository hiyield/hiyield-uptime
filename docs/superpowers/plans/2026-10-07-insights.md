# Insights & Board Charts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add write-time rollup tables, board overview tiles + per-row 24h uptime bars and response sparklines, and a new `/insights` page with downtime/incident charts and rankings.

**Architecture:** MonitorDO upserts two rollup rows (30-minute and daily) per tick from a pure `rollupDelta()`. Board and Insights APIs read only rollups (plus incidents for downtime), aggregated by pure, unit-tested helpers. Charts are small hand-built SVG/HTML Vue components following the dataviz skill (thin marks, hover tooltips, table views, status never colour-only).

**Tech Stack:** existing — Nuxt 4 SPA (Nuxt UI 4.8.0 pinned, forced dark theme), Cloudflare Durable Objects + D1, Drizzle, Zod 4, Vitest 4 + `@cloudflare/vitest-pool-workers`.

**Spec:** `docs/superpowers/specs/2026-10-07-insights-design.md`

- Branch `feat/insights` (off `main` @ 6b04275). Node 24: prefix every npm/npx command with `source ~/.nvm/nvm.sh && nvm use v24.13.0 >/dev/null && `.
- The user may have `npm run dev` running on :3000 — never start/stop it; never deploy.

- Commit trailers: `Co-Authored-By: <implementer's actual model> <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01Y9rygLhSyKkruyMHZnhRJT`.
- `server/engine/**`, `shared/**` and unit-tested `server/utils/*` use explicit relative imports only (no Nitro/Nuxt auto-imports).
- All timestamps are epoch ms. Buckets: 30 minutes (`1_800_000` ms); days are **UTC** (`86_400_000` ms).
- Rollup counting: only `region = 'primary'` checks. `failures` = `ok=false AND confirmed=true AND maintenance=false`; `blips` = `ok=false AND confirmed=false AND maintenance=false`; `maintenance` = checks taken in maintenance. Response aggregates over non-null `response_ms`.
- Uptime % = `1 − Σfailures / Σ(checks − maintenance)`, 2 dp, `null` when the denominator is 0 (existing `uptimePercent(total, failures)` with `total = checks − maintenance`).
- Retention: `rollup_30m` 8 days, `rollup_daily` 400 days.
- Board windows: 48 half-hour buckets ending with the current (partial) bucket; 30 UTC days ending today; 14 UTC days ending today for incidents.
- Insights ranges: `7d · 30d · 90d · 1y` (= 7/30/90/365 UTC days ending today); default `30d`; `1y` aggregates days into 7-day weeks.
- Chart status colours on the dark surface `#001313`: up `#00faa0`, blip `#fbbf24`, down `#ef4444`, maintenance `#0ea5e9`, none `#1f2b2b`. Uptime-bar heights: down 100%, blip 75%, up 50%, maintenance 50%, none 25%. (Validated with the dataviz validator, `--pairs all`: CVD/normal-vision/contrast PASS; lightness band FAIL accepted — these are status colours whose lightness differences are what keep red/green apart under CVD, and height is a second encoding.)
- Charts: thin marks, recessive gridlines (`#163636`), muted-white axis text (`rgba(255,255,255,0.6)`), tooltips on the elevated surface (`#0a2a2a`, border `#1f4545`), hover tooltip on every mark, "View as table" on every Insights chart/list, explicit empty states. No dual axes.

## Review Focus

1. **Fresh install / no rollup data yet** — board tiles show "—", bars are all grey, sparklines empty, Insights shows its empty state; never `NaN`, `Infinity` or a crash. Tests: Task 5 (`empty rollups`), Task 6 (`no data`).
2. **Incident spanning a window edge or still open** — downtime is clipped to the window/bucket and an open incident counts up to `now`. Tests: Task 4 (all split cases).
3. **Monitor created mid-window or with sparse checks** — buckets with no rows render `none`/`null`, not zero uptime or zero ms. Tests: Task 5 (`gaps`).
4. **Backfill run twice** — idempotent; second run yields identical rows. Test: Task 3 (`idempotent`).
5. **Paused mid-tick** — an aborted tick writes no rollup rows. Test: Task 2 (assertions added to the existing pause/delete race tests).

```ts
import { DAY_MS, ROLLUP_30M_MS } from '../../shared/utils/constants'
import type { CheckResult } from './types'

export interface RollupDelta {
  checks: number
  failures: number
  blips: number
  maintenance: number
  respSum: number
  respCount: number
  respMax: number
}

export const bucket30m = (ms: number): number => Math.floor(ms / ROLLUP_30M_MS) * ROLLUP_30M_MS
export const dayStart = (ms: number): number => Math.floor(ms / DAY_MS) * DAY_MS

/** One primary check's contribution to a rollup row. Pure. */
export function rollupDelta(check: CheckResult, opts: { confirmed: boolean; maintenance: boolean }): RollupDelta {
  const failed = !check.ok && !opts.maintenance
  const ms = check.responseMs
  return {
    checks: 1,
    failures: failed && opts.confirmed ? 1 : 0,
    blips: failed && !opts.confirmed ? 1 : 0,
    maintenance: opts.maintenance ? 1 : 0,
    respSum: ms ?? 0,
    respCount: ms === null ? 0 : 1,
    respMax: ms ?? 0
  }
}
```

```ts
import { sql } from 'drizzle-orm'
import { bucket30m, dayStart, type RollupDelta } from './rollup'

// Column names are fixed literals, never input — safe to inline as raw SQL.
const ROLLUP_ACCUMULATE = {
  checks: sql.raw('checks + excluded.checks'),
  failures: sql.raw('failures + excluded.failures'),
  blips: sql.raw('blips + excluded.blips'),
  maintenance: sql.raw('maintenance + excluded.maintenance'),
  respSum: sql.raw('resp_sum + excluded.resp_sum'),
  respCount: sql.raw('resp_count + excluded.resp_count'),
  respMax: sql.raw('max(resp_max, excluded.resp_max)')
}

/** Adds one check's delta to its 30-minute and daily rollup rows (insert or accumulate). */
export async function upsertRollups(db: EngineDb, monitorId: string, checkedAt: number, delta: RollupDelta): Promise<void> {
  const values = { monitorId, ...delta }
  await db
    .insert(schema.rollup30m)
    .values({ ...values, bucketStart: bucket30m(checkedAt) })
    .onConflictDoUpdate({ target: [schema.rollup30m.monitorId, schema.rollup30m.bucketStart], set: ROLLUP_ACCUMULATE })
  await db
    .insert(schema.rollupDaily)
    .values({ ...values, dayStart: dayStart(checkedAt) })
    .onConflictDoUpdate({ target: [schema.rollupDaily.monitorId, schema.rollupDaily.dayStart], set: ROLLUP_ACCUMULATE })
}
```

```ts
import * as schema from '../db/schema'
import { bucket30m, dayStart } from '../engine/rollup'
import {
  CHECK_RETENTION_DAYS,
  DAY_MS,
  ROLLUP_30M_RETENTION_DAYS,
  ROLLUP_DAILY_RETENTION_DAYS
} from '../../shared/utils/constants'
import type { Db } from './db'

export async function pruneRollups(db: Db, now: number): Promise<void> {
  await db.delete(schema.rollup30m).where(lt(schema.rollup30m.bucketStart, now - ROLLUP_30M_RETENTION_DAYS * DAY_MS))
  await db.delete(schema.rollupDaily).where(lt(schema.rollupDaily.dayStart, now - ROLLUP_DAILY_RETENTION_DAYS * DAY_MS))
}

const AGGREGATES = sql.raw(`count(*),
  sum(case when ok = 0 and confirmed = 1 and maintenance = 0 then 1 else 0 end),
  sum(case when ok = 0 and confirmed = 0 and maintenance = 0 then 1 else 0 end),
  sum(case when maintenance = 1 then 1 else 0 end),
  coalesce(sum(response_ms), 0),
  count(response_ms),
  coalesce(max(response_ms), 0)`)

/**
 * Rebuilds rollups from raw primary checks. Idempotent (delete-then-insert over the rebuilt range).
 * 30-minute rows only within their retention window. The oldest day is skipped when raw pruning
 * has already cut into it, so a complete live-written row is never replaced by a partial one.
 * Run once after deploying rollups; avoid running while monitors are mid-tick in that range.
 */
export async function backfillRollups(db: Db, now: number): Promise<{ from30m: number | null; fromDay: number | null }> {
  const [row] = await db
    .select({ min: sql<number | null>`min(${schema.checks.checkedAt})` })
    .from(schema.checks)
    .where(eq(schema.checks.region, 'primary'))
  const min = row?.min == null ? null : Number(row.min)
  if (min === null) return { from30m: null, fromDay: null }

  const from30m = Math.max(bucket30m(min), bucket30m(now - ROLLUP_30M_RETENTION_DAYS * DAY_MS))
  let fromDay = dayStart(min)
  const rawPruneEdge = now - CHECK_RETENTION_DAYS * DAY_MS
  if (min > fromDay && fromDay < rawPruneEdge + DAY_MS) fromDay += DAY_MS

  await db.delete(schema.rollup30m).where(gte(schema.rollup30m.bucketStart, from30m))
  await db.run(sql`insert into rollup_30m (monitor_id, bucket_start, checks, failures, blips, maintenance, resp_sum, resp_count, resp_max)
    select monitor_id, (checked_at / 1800000) * 1800000, ${AGGREGATES}
    from checks where region = 'primary' and checked_at >= ${from30m}
    group by monitor_id, (checked_at / 1800000) * 1800000`)

  await db.delete(schema.rollupDaily).where(gte(schema.rollupDaily.dayStart, fromDay))
  await db.run(sql`insert into rollup_daily (monitor_id, day_start, checks, failures, blips, maintenance, resp_sum, resp_count, resp_max)
    select monitor_id, (checked_at / 86400000) * 86400000, ${AGGREGATES}
    from checks where region = 'primary' and checked_at >= ${fromDay}
    group by monitor_id, (checked_at / 86400000) * 86400000`)

  return { from30m, fromDay }
}
```

```ts
export interface IncidentSpan {
  monitorId: string
  startedAt: number
  resolvedAt: number | null
}

/** Half-open interval [start, end). */
export interface Period {
  start: number
  end: number
}

export function overlapMs(i: IncidentSpan, p: Period, now: number): number {
  const end = Math.min(i.resolvedAt ?? now, p.end)
  const start = Math.max(i.startedAt, p.start)
  return Math.max(0, end - start)
}

export function downtimeByPeriod(
  incidents: IncidentSpan[],
  periods: Period[],
  now: number
): { ms: number; monitorIds: string[] }[] {
  return periods.map((p) => {
    let ms = 0
    const ids: string[] = []
    for (const i of incidents) {
      const o = overlapMs(i, p, now)
      if (o <= 0) continue
      ms += o
      if (!ids.includes(i.monitorId)) ids.push(i.monitorId)
    }
    return { ms, monitorIds: ids }
  })
}

export function downtimeByMonitor(incidents: IncidentSpan[], p: Period, now: number): Map<string, number> {
  const out = new Map<string, number>()
  for (const i of incidents) {
    const o = overlapMs(i, p, now)
    if (o > 0) out.set(i.monitorId, (out.get(i.monitorId) ?? 0) + o)
  }
  return out
}
```

```ts
  failures: number
  blips: number
  maintenance: number
  respSum: number
  respCount: number
  respMax: number

  failures: number
  avgMs: number | null

export interface MonitorCharts {

  barStats: BarStat[]
  spark: (number | null)[]

  uptime24h: number | null
  uptime30d: number | null
  incidents7d: number
  incidentsPrev7d: number
  avgResponse24h: number | null

export function barState(c: Counters | undefined): BarState {
  if (!c || c.checks === 0) return 'none'
  if (c.failures > 0) return 'down'
  if (c.blips > 0) return 'blip'
  if (c.maintenance > 0) return 'maintenance'
  return 'up'
}

export function bucketStarts(now: number, count: number, size: number): number[] {
  const last = Math.floor(now / size) * size
  return Array.from({ length: count }, (_, i) => last - (count - 1 - i) * size)
}

const sum = (rows: Counters[]): Counters =>
  rows.reduce(
    (a, r) => ({
      checks: a.checks + r.checks,
      failures: a.failures + r.failures,
      blips: a.blips + r.blips,
      maintenance: a.maintenance + r.maintenance,
      respSum: a.respSum + r.respSum,
      respCount: a.respCount + r.respCount,
      respMax: Math.max(a.respMax, r.respMax)
    }),
    { checks: 0, failures: 0, blips: 0, maintenance: 0, respSum: 0, respCount: 0, respMax: 0 }
  )

export function fleetUptime(rows: Counters[]): number | null {
  const s = sum(rows)
  return uptimePercent(s.checks - s.maintenance, s.failures)
}

export function avgMs(c: Counters | undefined): number | null {
  return c && c.respCount > 0 ? Math.round(c.respSum / c.respCount) : null
}
```

- Produces:
  ```ts
  const RANGE_DAYS = { '7d': 7, '30d': 30, '90d': 90, '1y': 365 } as const
  type RangeKey = keyof typeof RANGE_DAYS
  insightsQuerySchema  // z.object({ range: z.enum(['7d','30d','90d','1y']).default('30d') })
  interface InsightsPeriod { start: number; end: number; downtimeMs: number; incidents: number; sites: { id: string; name: string }[] }
  interface Insights {
    range: RangeKey; from: number; to: number
    tiles: { uptime: number | null; incidents: number; downtimeMs: number; mttrMs: number | null }
    periods: InsightsPeriod[]          // days, or 7-day weeks for 1y
    worst: { id: string; name: string; downtimeMs: number; incidents: number; uptime: number | null }[]
    slowest: { id: string; name: string; avgMs: number; maxMs: number }[]
  }
  getInsights(db: Db, range: RangeKey, now: number): Promise<Insights>
  ```
  - `from` = start of the first UTC day in range (`bucketStarts(now, days, DAY_MS)[0]`), `to` = `now`.
  - Periods: one per day `[dayStart, dayStart+DAY)` with the last period ending at `now`; for `1y`, consecutive 7-day chunks from `from` (the last chunk may be shorter), last ending at `now`.
  - `tiles.uptime` = `fleetUptime` of all `rollup_daily` rows in range. `tiles.incidents` = incidents with `startedAt ∈ [from, now)`. `tiles.downtimeMs` = Σ overlap of incidents with `[from, now)`. `tiles.mttrMs` = mean `resolvedAt − startedAt` of incidents with `resolvedAt ∈ [from, now)`, rounded; null if none.
  - Period `incidents` = started in the period; `sites` = names of monitors with downtime in the period.
  - `worst`: monitors with downtime > 0 in range, sorted by downtime desc, then name; top 10; `incidents` = started in range; `uptime` from that monitor's daily rows.
  - `slowest`: monitors with `respCount > 0` in range; `avgMs` = round(Σsum/Σcount); `maxMs` = max of `respMax`; sorted by `avgMs` desc; top 10.
  - Incidents query: `startedAt < now AND (resolvedAt IS NULL OR resolvedAt > from)`, joined to `monitors` for names.

```ts
import { and, eq, gte, gt, isNull, lt, or } from 'drizzle-orm'
import { z } from 'zod'
import * as schema from '../db/schema'
import { DAY_MS } from '../../shared/utils/constants'
import { avgMs, bucketStarts, fleetUptime, type Counters } from './boardCharts'
import { downtimeByMonitor, downtimeByPeriod, type IncidentSpan, type Period } from './downtime'
import type { Db } from './db'

export const RANGE_DAYS = { '7d': 7, '30d': 30, '90d': 90, '1y': 365 } as const
export type RangeKey = keyof typeof RANGE_DAYS
export const insightsQuerySchema = z.object({ range: z.enum(['7d', '30d', '90d', '1y']).default('30d') })

export interface InsightsPeriod {
  start: number
  end: number
  downtimeMs: number
  incidents: number
  sites: { id: string; name: string }[]
}
export interface Insights {
  range: RangeKey
  from: number
  to: number
  tiles: { uptime: number | null; incidents: number; downtimeMs: number; mttrMs: number | null }
  periods: InsightsPeriod[]
  worst: { id: string; name: string; downtimeMs: number; incidents: number; uptime: number | null }[]
  slowest: { id: string; name: string; avgMs: number; maxMs: number }[]
}

function buildPeriods(range: RangeKey, now: number): Period[] {
  const days = bucketStarts(now, RANGE_DAYS[range], DAY_MS)
  const step = range === '1y' ? 7 : 1
  const out: Period[] = []
  for (let i = 0; i < days.length; i += step) {
    const start = days[i]!
    const endIdx = i + step
    out.push({ start, end: endIdx < days.length ? days[endIdx]! : now })
  }
  return out
}

export async function getInsights(db: Db, range: RangeKey, now: number): Promise<Insights> {
  const periods = buildPeriods(range, now)
  const from = periods[0]!.start
  const whole: Period = { start: from, end: now }

  const names = new Map((await db.select({ id: schema.monitors.id, name: schema.monitors.name }).from(schema.monitors)).map((m) => [m.id, m.name]))
  const daily = await db.select().from(schema.rollupDaily).where(gte(schema.rollupDaily.dayStart, from))
  const i = schema.incidents
  const incidents = await db
    .select({ monitorId: i.monitorId, startedAt: i.startedAt, resolvedAt: i.resolvedAt })
    .from(i)
    .where(and(lt(i.startedAt, now), or(isNull(i.resolvedAt), gt(i.resolvedAt, from))))
  const spans: IncidentSpan[] = incidents

  const startedIn = (p: Period) => spans.filter((s) => s.startedAt >= p.start && s.startedAt < p.end)
  const resolved = spans.filter((s) => s.resolvedAt !== null && s.resolvedAt >= from && s.resolvedAt < now)
  const perPeriod = downtimeByPeriod(spans, periods, now)
  const perMonitorDown = downtimeByMonitor(spans, whole, now)

  const dailyBy = new Map<string, Counters[]>()
  for (const r of daily) dailyBy.set(r.monitorId, [...(dailyBy.get(r.monitorId) ?? []), r])

  const worst = [...perMonitorDown.entries()]
    .filter(([id]) => names.has(id))
    .map(([id, ms]) => ({
      id,
      name: names.get(id)!,
      downtimeMs: ms,
      incidents: startedIn(whole).filter((s) => s.monitorId === id).length,
      uptime: fleetUptime(dailyBy.get(id) ?? [])
    }))
    .sort((a, b) => b.downtimeMs - a.downtimeMs || a.name.localeCompare(b.name))
    .slice(0, 10)

  const slowest = [...dailyBy.entries()]
    .filter(([id]) => names.has(id))
    .map(([id, rows]) => {
      const respSum = rows.reduce((a, r) => a + r.respSum, 0)
      const respCount = rows.reduce((a, r) => a + r.respCount, 0)
      return { id, name: names.get(id)!, respCount, avg: avgMs({ ...rows[0]!, respSum, respCount }), maxMs: Math.max(...rows.map((r) => r.respMax)) }
    })
    .filter((r) => r.respCount > 0 && r.avg !== null)
    .map((r) => ({ id: r.id, name: r.name, avgMs: r.avg!, maxMs: r.maxMs }))
    .sort((a, b) => b.avgMs - a.avgMs || a.name.localeCompare(b.name))
    .slice(0, 10)

  return {
    range,
    from,
    to: now,
    tiles: {
      uptime: fleetUptime(daily),
      incidents: startedIn(whole).length,
      downtimeMs: [...perMonitorDown.values()].reduce((a, b) => a + b, 0),
      mttrMs: resolved.length
        ? Math.round(resolved.reduce((a, s) => a + (s.resolvedAt! - s.startedAt), 0) / resolved.length)
        : null
    },
    periods: periods.map((p, idx) => ({
      start: p.start,
      end: p.end,
      downtimeMs: perPeriod[idx]!.ms,
      incidents: startedIn(p).length,
      sites: perPeriod[idx]!.monitorIds.filter((id) => names.has(id)).map((id) => ({ id, name: names.get(id)! }))
    })),
    worst,
    slowest
  }
}
```
